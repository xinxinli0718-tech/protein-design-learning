酶设计入门（3 周）

目标：理解催化位点设计思路，用 LigandMPNN + Rosetta 能量验证完成一个入门级催化设计课题。

先摆正预期 酶设计是蛋白质设计里成功率最低、实验闭环最长、门槛最高的分支。3 周课程带你完整走一遍「催化几何定义 → 口袋序列设计 → 计算验证 → 进化衔接」的入门流程，产出的是值得送实验的计算候选与设计文档——不要期待第一轮就得到高活性新酶，那是领域内多年研究才做到的。
前置要求 已完成「de novo 实战」或等同能力（能跑 RFdiffusion + ProteinMPNN/LigandMPNN + ColabFold），并会用 ChimeraX 选择/导出残基与配体。

第 1 周：酶设计原理：theozyme 与催化残基几何

预计 3–4 小时 · 产出：一份可执行的「设计目标描述」

1.1 酶为什么快：过渡态稳定化

酶不直接「推动」反应，而是把底物约束在活性位点里，用精确排布的官能团稳定反应的过渡态，从而降低活化能。因此酶设计的第一性问题不是「找个能结合底物的口袋」，而是：哪些功能基团、以什么几何关系，去稳定哪一步的过渡态？

1.2 Theozyme：把催化理想化成一个几何约束

Theozyme（theoretical enzyme）是用量子化学/过渡态模型算出的「最小理想催化排布」：催化残基侧链原子相对底物/过渡态模型的距离、角度、二面角。它不是完整蛋白，而是 3–5 个残基的理想几何——之后所有设计（scaffolding、序列设计）都在「保住这套几何」的前提下进行。

  • 经典案例：Kemp 消除酶（Röthlisberger 2008，Nature）、retro-aldol 酶（Jiang 2008，Science）、Diels-Alderase（Siegel 2010，Science）都是先定义 theozyme，再 scaffold + 进化；
  • 常见催化基团：Ser-His-Asp/Glu 三联体（水解）、Cys-His 或金属锌配位（半胱氨酸/锌蛋白酶）、广义酸碱（Glu/Lys）、亲核进攻（Ser/Cys/Thr）。

对零计算化学背景的同学，最友好的入门方式不是自己算 QM，而是拿一个已知天然酶的结构，逆向抽取它的催化几何：把催化残基与过渡态类似物（TS analog）/抑制剂复合物当作「实验版 theozyme」。

1.3 本课程的项目选择（重要）

建议二选一：

  1. 路线 A（推荐给新手）：口袋重塑。选一个底物/抑制剂结构清楚的水解酶（酯酶/蛋白酶），保持催化三联体残基，用 LigandMPNN 重设计周围口袋残基，目标是产生「包围同一底物的新序列变体」——流程完整、成功标准清楚；
  2. 路线 B（挑战）：motif scaffolding 全新酶。沿用 de novo 课技能，把 3–5 个催化残基的 theozyme 坐标 scaffold 成全新蛋白。计算上更帅，但实验成功率低得多。

1.4 写出你的设计目标描述（本周产出）

用一页纸回答六件事：①反应与底物（哪根键断裂/形成）；②你想稳定哪个过渡态或中间体；③催化残基清单与角色（亲核/酸碱/配位）；④关键几何约束（至少 3 组原子间距离或角度，单位 Å/度）；⑤底物结合所需的化学互补（疏水口袋、氢键供受体）；⑥实验验证用什么读出活性（比色/荧光/质谱/偶联酶法）。

找不到好例子？ RCSB 搜「esterase + inhibitor complex」「protease + transition state analog」，选择分辨率 ≤ 2.5 Å、抑制剂结合构象清楚的条目。别一上来碰需要辅因子再生或多步反应体系的复杂酶。
本周作业：选定路线 A 或 B；下载含底物/TS analog 的复合物 PDB（含配体）；在 ChimeraX 中标出催化残基，量出 3 组距离/角度；完成 1 页设计目标描述。W2 开始做口袋序列设计。

第 2 周：口袋设计：LigandMPNN 与底物结合

预计 5–7 小时 · 产出：口袋设计候选（每轮 8–16 条序列）

2.1 为什么这里用 LigandMPNN 而不是 ProteinMPNN

ProteinMPNN 只知道蛋白骨架；LigandMPNN 额外把小分子/辅因子/核酸/金属离子的原子坐标作为上下文输入，逐位判断「哪个氨基酸会与配体形成好接触」。设计口袋时，这是对的方法——它见过的训练数据里包含大量蛋白–配体复合物，能学到氢键供受体互补等化学直觉。

2.2 准备输入文件（本周花时间最多的一步）

  1. 从复合物里保留：催化域蛋白链 + 底物/TS analog/抑制剂（HETATM）；
  2. 去掉无关配体、去垢剂、水分子与多余金属；
  3. 检查配体没有残缺、占据率正常、元素/原子名完整；
  4. 把文件存为 pocket.pdb，链 ID 唯一。
配体文件别糊弄 LigandMPNN 能不能看到并正确利用配体，取决于配体原子是否在 PDB 里干净存在。如果是从别的软件导出的结构，先确认配体不是以残缺片段/错误元素名存在，否则结果没有意义。

2.3 运行第一轮：锁住催化残基，设计口袋

  • 催化残基必须固定：用 --fixed_residues 逐位列出（格式 链+编号，如 A48 A82 A109）；
  • 只重设计离配体近的口袋：在 ChimeraX 里选出配体 6–8 Å 内的蛋白残基（select :A within 6 of ligand），用 --redesigned_residues 指定这些位置；
  • 每个骨架采 8 条：--number_of_batches 8 --temperature 0.15。
git clone https://github.com/dauparas/LigandMPNN.git
cd LigandMPNN
bash get_model_params.sh "./model_params"
python run.py \
  --model_type "ligand_mpnn" \
  --pdb_path pocket.pdb \
  --fixed_residues "A48 A82 A109" \
  --redesigned_residues "A19 A21 A22 A23 A46 A47 A49 A83 A107 A108 A110" \
  --number_of_batches 8 \
  --temperature 0.15 \
  --out_folder lm_round1

输出 FASTA 标题里有两组重要指标：overall_confidence 与 ligand_confidence（对配体近旁重设计残基的置信度，越高模型越自信）。它们只适合相对排序，请勿当作成功概率。

2.4 检查候选：回到 ChimeraX 看化学

  1. 把每一条候选序列「回贴」到骨架上（LigandMPNN 会在 outputs 里给出带序列的 PDB），逐一打开；
  2. 检查配体周围的极性残基是否形成有意义的氢键/盐桥，而不是随机堆满带电残基；
  3. 检查口袋内壁疏水/亲水是否与底物化学性质匹配；
  4. 确认催化残基没有被无关侧链挡住，几何与 W1 记录一致；
  5. 淘汰序列里出现未配对 Cys、过长同聚段等问题的候选。
进阶（可选） 想评估配体到底贡献了多少信息，可跑一组对照：加 --ligand_mpnn_use_atom_context 0 屏蔽配体原子，比较同一骨架在「看得见配体 vs 看不见配体」时的序列差异。差异大说明设计确实在响应配体化学。
本周作业：跑 2 轮以上（可换温度/换骨架/调口袋范围）；整理候选表：骨架、序列、overall/ligand confidence、接触配体的残基与相互作用类型；挑出 Top15 进 W3 验证。

第 3 周：能量验证、进化衔接与复盘

预计 5–7 小时 · 产出：候选酶设计包 + 进化/实验路线图

3.1 三条独立的验证线（缺一不可）

① 结构自洽：把候选序列（保留配体的蛋白部分）丢进 ColabFold，确认整体能折叠：pTM ≥ 0.80、催化残基区 pLDDT ≥ 85、无大段低置信。设计只是「纸上序列」时最容易在这一步暴露折叠不自洽。

② 能量检查（Rosetta）：用 Rosetta/PyRosetta 对候选模型做一次 all-atom relax（ref2015 能量函数），看 relax 后：有没有原子严重碰撞（fa_rep 异常大）、内部能量是否随 relax 大幅改善（说明原模型有张力）、催化几何是否被 relax 破坏。这步不需要跑成千上万次，每轮筛掉能量烂掉的候选即可。

③ 进化/保守性线索：把设计的序列与天然酶家族比对（EVcouplings、ConSurf 或简单 BLAST），看催化位点周围设计出的残基是否符合天然蛋白在该位置的化学偏好。天然酶在千万年进化里「喜欢」什么，是免费的先验知识——例如配体结合口袋极少塞满同种电荷。

3.2 三门成绩合一，产出送测包

  1. 回测 + 能量 + 保守性都通过的候选通常只剩 3–8 条；
  2. 每一条准备：FASTA、设计 PDB、relax 后 PDB、ColabFold 预测 PDB、催化几何检查表（配位距离/角度）、口袋相互作用截图；
  3. 写清楚「如果我是实验者，会先测哪一条、为什么」——这个排序比罗列分数更能体现你的判断力。

3.3 从候选到活性：定向进化才是常态

历史案例反复说明：设计出来的初代酶活性常比天然酶低几个数量级，但定向进化可以再拉高 10⁴–10⁶ 倍。衔接实验时不要只问「有没有活性」，要规划：

  • 先证折叠：表达 + 纯化 + CD/SEC/热稳定性（与 de novo 课一致）；
  • 再建读出：选对底物类似物与灵敏的活性检测（荧光/比色最省事），做好阳性对照（天然酶）与阴性对照（催化残基突变体）；
  • 后做进化：围绕口袋做饱和突变/易错 PCR，用酵母展示或高通量孔板筛选。每轮进化后把「哪几个位置在变」反馈回计算模型，理解设计假设哪里错了。

3.4 复盘：这门课真正教会你的三件事

  • 酶设计的起点是化学（过渡态、几何），不是跑模型——几何定义错了，后面所有计算都是精致的错误；
  • 计算筛选淘汰的是「明显不合理」，剩下的候选仍要实验兜底，进化是设计闭环的一部分而非事后补救；
  • 你会读「设计酶」文献了：知道 they 的 theozyme 怎么定义、scaffold 怎么保几何、回测看什么指标、为什么最后总要进化。
毕业作业：输出完整「候选酶设计包」（设计目标描述 + 候选表 + 三条验证线的结果文件与截图 + 送测/进化路线图）；写一段 300 字左右的「下一步计划」，想象你拿到经费/合作者后会怎么执行。
