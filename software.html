AlphaFold2 / AlphaFold3 结构预测

Google DeepMind · 2021 / 2024 · 2024 诺贝尔化学奖

正问题的王炸：给定序列预测结构。AlphaFold2 精度达到实验级；AlphaFold3 扩展到蛋白—核酸—小分子配体复合物和翻译后修饰预测。

  • 网页版：AlphaFold3 Server（免费、无需 GPU）
  • 本地版：代码开源，但需要较强 GPU
  • 设计流水线里主要用来做「自洽性回测」
AF3 Server GitHub AlphaFold 数据库

ColabFold 结构预测

免费 · 浏览器即用 · 新手首选

AlphaFold2 的加速重实现（用 MMseqs2 快速搜索同源序列），不用装任何东西，在 Google Colab 里点两下就跑。单体、复合物都能预测。

  • 输出 pLDDT、pTM、ipTM、PAE 和模型 PDB
  • 也支持 RoseTTAFold2 模式
GitHub（含 Colab 链接） 直接打开 Colab

ESMFold 结构预测

Meta AI · 单序列预测 · 快

不需要 MSA，一条序列几秒出结构。精度略低于 AlphaFold，但特别适合「快速浏览大量序列」和设计流水线里的粗筛。预测可以在网页上直接用，也整合在 ESM 仓库里。

ESM Atlas 在线预测 GitHub

RoseTTAFold / RF2 结构预测

Baker lab · 2021 · 三轨注意力网络

与 AlphaFold2 同期发布的预测器，用更轻的「序列+结构+MSA」三轨网络。RF2 在线服务器可预测复合物；RoseTTAFold All-Atom 扩展到配体小分子。与 RFdiffusion 是同一家族。

GitHub ROBETTA 服务器

OpenFold 结构预测

开放复现 AF2 · 可训练 · 研究友好

独立复现并开源训练的 AlphaFold2，支持从头训练和微调，是研究「模型内部发生了什么」和定制预测的首选框架。如果你未来想改模型、做新任务，从这里开始。

GitHub

Boltz-1 / Boltz-2 结构预测

开源 AF3 级模型 · 2024/2025

让「AlphaFold3 级别」的复合物预测完全开源：蛋白、核酸、小分子配体、金属离子都能处理。Boltz-2 进一步支持共价修饰和更广的化学空间，正在成为本地预测的标准选择。

GitHub 官网

传统预测与同源建模 结构预测

I-TASSER / SWISS-MODEL / MODELLER

深度学习之前的主流路线，理解它们能帮你读懂老文献：I-TASSER 靠线程化组装模板片段；SWISS-MODEL 和 MODELLER 用已知同源结构搭模型。现在主要用于「没有同源序列时」的补充和教学。

ProteinMPNN 序列设计

Baker lab · 2022 · 逆折叠 SOTA

给一个骨架设计序列的默认工具。图神经网络逐位预测「这里放哪个氨基酸最合适」，可以固定某些残基（比如功能位点），可以生成多条候选。实验成功率远高于传统方法。

  • 标准用法：RFdiffusion 出的骨架 → ProteinMPNN 出序列
  • 官方 Colab 可以直接跑，无需 GPU 也能用 CPU 完成小任务
GitHub Colab

LigandMPNN 序列设计

ProteinMPNN 的扩展 · 2023

序列设计时把口袋里的配体、辅因子、核酸、金属离子也考虑进去——设计酶口袋或设计「围绕小分子」的蛋白时比 ProteinMPNN 更合适。

GitHub

ESM / ESM2 / ESM3 序列设计

Meta · 蛋白语言模型

把序列当语言学的模型。ESM2 可用于序列合理性打分和突变效应预测；ESM3 能按「序列+结构+功能」条件联合生成，比如给定一个功能位点让模型补齐其余部分，甚至设计荧光蛋白。

ESM 仓库 ESM Atlas

RFdiffusion 生成式设计

Baker lab · 2023 · 结构扩散模型

当前从头设计的主角。从随机噪声扩散出全新骨架，支持多种任务：motif scaffolding（把功能基序装进新支架）、binder design（对着靶点表面长结合蛋白）、对称自组装、单体/复合物设计。生成的结构与目标功能位点高度一致。

  • binder 模式需要提供靶点结构文件
  • 建议在带 GPU 的 Colab 或本地跑
GitHub Colab 示例

Chroma 生成式设计

Generate Bio · 2023 · 程序化生成

另一个扩散式生成模型，特色是「程序化约束」：可以指定对称性、尺寸、甚至掩码区域，直接采样完整复合物或功能化的蛋白。API 和本地代码都开源，值得和 RFdiffusion 对比着玩。

GitHub 官网

FrameDiff / Genie（了解即可）生成式设计

研究型方法 · 理解扩散概念用

早期把扩散模型用在蛋白骨架上的学术方法（SE(3) 扩散、等变图网络）。现在主流工作流不用它们，但读 2022–2023 年的文献会频繁遇到，值得知道「RFdiffusion 站在谁的肩膀上」。

FrameDiff 论文

Rosetta 经典设计套件

UW Baker lab · 20+ 年历史 · 设计界标准

物理+统计能量函数的集大成者，从结构预测到序列设计、对接、酶设计全覆盖。核心概念：能量函数打分、蒙特卡洛/模拟退火采样、relax（结构松弛）、FixBB（固定骨架设计序列）、FastDesign（骨架+序列联合优化）。

  • 命令行应用（Linux/macOS），文档非常全
  • 理解它 = 理解设计的「物理内核」
官网 文档 教程

PyRosetta 经典设计套件

Rosetta 的 Python 接口 · 学习首选

用 Python 操作 Rosetta：读结构、打分、design、relax。配套教程从安装到高级设计逐步讲解，比命令行应用更适合理解每一步在做什么。许多 Baker lab 入门课程都基于它。

官网 教程

Foldit 经典 · 入门

游戏化蛋白折叠 · 玩家参与科研

把蛋白折叠做成解谜游戏：拖拽、摇摆、打分实时反馈。零基础也能玩，玩家社区甚至帮科学家解出了晶体结构（Khatib 2011）。强烈推荐作为「第一个动手项目」。

官网（免费下载）

PyMOL 可视化

结构生物学最常用的可视化软件

射线图、表面、静电、突变标注、交互式脚本。文献里绝大多数结构图都是它做的。开源版功能足够学习，教学版也免费。

官网 Wiki

UCSF ChimeraX 可视化

现代交互可视化 · cryo-EM 友好

处理密度图、体积数据、界面分析非常顺手，交互界面现代，还有大量教学资源。做 cryo-EM 的你大概率已经很熟——设计这边它同样适合看模型与密度对比、算界面接触。

官网

VMD 可视化

MD 轨迹与结构分析

做分子动力学模拟、看轨迹、算相互作用时最常用。设计候选做 MD 稳定性验证时会用到。

官网

Coot / Phenix 可视化 · 实验结构

实验结构精修（晶体 & cryo-EM）

拿到设计蛋白的实验结构后，用 Coot 手动调模型、Phenix 做精修。这是「设计闭环」的最后验证环节——你的实验结构会和设计模型对比，回填到 PDB 里。

Phenix Coot

实验验证工具箱 实验验证

设计只完成一半，实验决定成败

计算设计产出候选序列后，实验闭环大致是：基因合成（Twist/GenScript）→ 表达纯化（大肠杆菌/酵母/哺乳动物细胞）→ 基本表征（SEC 判断是否单分散、CD/Tm 看折叠和稳定性、质谱看分子量）→ 功能/结合验证（BLI/SPR、酵母展示或噬菌体展示筛库）→ 结构验证（晶体或 cryo-EM）。

  • 酵母展示/噬菌体展示：高通量筛亲和力
  • cryo-EM：你的主场，直接看设计对不对
Addgene（质粒） PDB（存结构）
